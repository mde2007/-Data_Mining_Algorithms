# -Data_Mining_Algorithms

1. Изучить заданные методы (алгоритмы) поиска данных.
2. Написать программу, выполняющую следующие действия:
➢ Формирование целочисленного массива А(2000):
а) с помощью генератора случайных чисел в указанном
пользователем диапазоне;
б) путем чтения заданного набора данных из файла; в) можно
воспользоваться массивом данных, сформированном в
Практической работе № 02.
➢ Поиск запрашиваемых данных в массиве А осуществляется
указанными в задании методами. (Исследуемые методы поиска
соответствует номеру, указанному в таблица распределения
вариантов)
➢ Сравнение полученных результатов, оценка времени решения
задачи (оценка эффективности). Полученные результаты записать в
файл.

Методы: 
Алгоритм линейного поиска
Интерполяционный поиск
Jump Search
Sentinel Linear Search (Дозорный линейный поиск)
